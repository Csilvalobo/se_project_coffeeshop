# Triple Peaks Coffee Shop

This is the second project of the Software Engineering program at TripleTen. It was created using HTML and CSS, based on the design brief.

## Project features

- Semantic HTML5
- Flexbox
- Positioning
- Flat BEM file structure
- A custom form
- CSS animation and transform

## Plan on improving the project

If I were to add anything else to the project it would be a link or a QR code in the "about" section where it mentions the free wifi.
That would make easier for people to tap on the "wifi" section and automatically get connected to the coffeeshop network.
